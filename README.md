# 机器遗忘平台 · 指令/噪声分类器

基于 **FastAPI + NumPy + SQLite** 的 SISA 风格机器遗忘（Machine Unlearning）演示系统：
语音数据管理员可按贡献者**永久撤回**样本，系统只重训受影响分片，从最早受影响切片的
前一切片检查点续算，保证结果与“剔除全部已撤回样本后从头训练”**逐位一致**
（float64 参数误差 ≤ 1e-10，实测为 0.0）。

## 快速启动

### Docker Compose（推荐）

```bash
docker compose up --build
```

打开 http://localhost:8000 。SQLite 数据持久化在命名卷 `unlearn-data` 中，
`docker compose restart` 后状态保留；`docker compose down -v` 可清空重来。

### 本地运行（开发）

```bash
pip install -r requirements.txt
uvicorn app.main:app --port 8000
```

## 模型与数据

- **60 条本地样本**：10 位贡献者 × 6 条，四维特征，标签为 指令(1)/噪声(0)，
  由固定种子确定性生成（`app/seed.py`）。
- **固定分片**：3 片 × 4 个有序切片 × 5 样本（样本 id 连续划分，次序固定）。
- **训练**：每片一个逻辑回归（4 维 + 偏置），零初始化；按固定次序**逐样本训练一遍**，
  SGD 学习率 **0.1**、动量 **0.9**（经典动量，动量缓冲跨切片延续）。
- **预测**：三片 sigmoid 概率的**均值**，≥0.5 判为“指令”。

## 遗忘机制

- 每个切片训练结束后保存检查点（权重 w、偏置 b **及动量缓冲**，float64 落 SQLite）。
- 撤回按贡献者永久生效（无撤销入口）。
- 重训时，每片从**本轮新撤回样本的最早受影响切片 k** 之前的检查点（k-1）续算
  k..4 切片；未受影响片完全不训练。k-1 处检查点对全部已撤回样本干净
  （任何含后来撤回样本的切片都会被更晚的轮次重写），故续算 ≡ 从头训练。
- 每轮结束与“剔除全部已撤回样本后从头训练”的参照模型逐片对比，
  最大参数误差写入轮次记录并在网页展示（阈值 1e-10）。

## 状态机（停供保证）

| 状态 | 含义 | 可预测 |
|---|---|---|
| READY | 全部撤回已消除 | ✓ |
| STOPPED | 已受理撤回，等待重训 | ✗ (409) |
| RETRAINING | 重训中（慢重训期间仍可提交新撤回） | ✗ (409) |
| FAILED | 重训失败或被重启打断，可重试 | ✗ (409) |

- 撤回与轮次提交共用同一把锁：撤回一旦落库即停供；轮次结束时若已有新撤回，
  直接接续下一轮，不会短暂恢复服务——**旧轮不会恢复被撤样本的影响**。
- 轮次结果（三片模型 + 代际 + 已处理撤回指针 + 状态）在**单个事务**内提交；
  预测端校验所有分片代际一致，**拒绝拼用新旧分片**。
- 进程在重训中途崩溃/重启：启动时把 RETRAINING 落为 FAILED，保持停供，
  网页“重试重训”按钮或 `POST /api/retry` 可恢复。

## 网页功能

- 状态横幅（状态/代际/活跃样本/待消除撤回）与重训进度条
- 四维特征预测（含三片各自概率；停供时显示拒绝原因）
- 贡献者列表与“永久撤回”按钮
- 对照校验（实时最大误差、分片误差、≤1e-10 判定）
- 重训历史（每轮消除的撤回、**实际重训切片**、对照误差、耗时）
- 60 条样本明细（片/切片/标签/撤回状态）

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/status` | 全量状态（状态机、进度、校验、轮次、样本） |
| POST | `/api/predict` | `{features:[x1..x4]}` → 概率与标签；停供时 409 |
| POST | `/api/withdraw` | `{contributor}` → 永久撤回并触发重训 |
| POST | `/api/retry` | FAILED/STOPPED 状态下重试重训 |

## 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `DB_PATH` | `./data/unlearn.db`（镜像内 `/data/unlearn.db`） | SQLite 路径 |
| `RETRAIN_SLICE_DELAY` | `0.6`（Compose 中 `0.8`） | 每切片人为延时（秒），便于演示慢重训 |
| `INJECT_FAILURE_AT` | 空 | 测试钩子：`轮次:片:切片` 命中时注入一次失败 |
| `UNLEARN_TEST_SHUTDOWN` | 空 | 置 `1` 时暴露 `POST /api/_shutdown`（仅自测用） |
